# Enterprise-L3-Spine-Leaf-Data-Center-Network-Design-Troubleshoot-Project
Cisco Packet Tracer data center network featuring a 2-spine, 3-leaf architecture, OSPF routing, redundant paths, VLAN segmentation, and network troubleshooting.

Project Overview

Designed and configured a Layer 3 spine–leaf data center network using Cisco Packet Tracer. The architecture consists of two spine switches and three leaf switches, providing redundant Layer 3 connectivity using OSPF.

Technologies Implemented

Cisco Layer 3 Switching

Spine–Leaf Network Architecture

OSPF Area 0

VLAN Segmentation

IP Addressing and Subnetting

Network Connectivity Testing and Troubleshooting

Project Highlights

Configured redundant spine-to-leaf connections.

Implemented OSPF routing between spine and leaf switches.

Configured separate VLANs and IP subnets for end devices.

Investigated packet loss and connectivity failures caused by overlapping VLANs and networks.

Verified connectivity following configuration corrections.

Project Limitations

VXLAN/EVPN overlays were not implemented due to Cisco Packet Tracer limitations.
